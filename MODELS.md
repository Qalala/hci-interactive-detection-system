# Model files (not included)

Large binary models are excluded from this repository. Place them beside the project as your local setup expects:

- `yolo11n.pt` / `yolo26m.pt` — YOLO weights used by the detection demos
- `shape_predictor_68_face_landmarks.dat` — dlib face landmark predictor
- `face_landmarker.task` — MediaPipe face landmarker task file

Download sources depend on the libraries you used during the course (Ultralytics YOLO, dlib model zoo, MediaPipe tasks).
